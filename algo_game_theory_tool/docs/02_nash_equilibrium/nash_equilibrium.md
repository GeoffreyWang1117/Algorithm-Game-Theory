# 纳什均衡 (Nash Equilibrium)

## 数学定义

策略组合 $s^* = (s_1^*, s_2^*, \ldots, s_n^*)$ 是 **纳什均衡**，如果对每个玩家 $i$：

$$u_i(s_i^*, s_{-i}^*) \geq u_i(s_i, s_{-i}^*) \quad \forall s_i \in S_i$$

即：**没有玩家能通过单方面改变策略来提高自己的效用**。

### 最佳响应 (Best Response)

策略 $s_i^*$ 是对 $s_{-i}$ 的 **最佳响应**，如果：

$$s_i^* \in \arg\max_{s_i \in S_i} u_i(s_i, s_{-i})$$

记 $BR_i(s_{-i})$ 为玩家 $i$ 对 $s_{-i}$ 的所有最佳响应集合。

### 纳什均衡的等价定义

$s^*$ 是纳什均衡 $\Leftrightarrow$ $s_i^* \in BR_i(s_{-i}^*)$ 对所有 $i$

即：**每个玩家都在对其他玩家策略的最佳响应**。

## 存在性

### Nash 定理 (1950)

**定理**：每个有限博弈至少存在一个纳什均衡（可能是混合策略）。

证明使用了 **Kakutani 不动点定理**。

### 纯策略纳什均衡

不是所有博弈都有纯策略纳什均衡：
- 囚徒困境：$(D, D)$ ✓
- 匹配硬币：不存在 ✗
- 石头剪刀布：不存在 ✗

## 计算方法

### 1. 枚举法（穷举搜索）

对于小规模有限博弈：

```python
for each strategy profile s:
    if s is a Nash equilibrium:  # 检查每个玩家是否在最佳响应
        output s
```

**复杂度**：$O(|S_1| \times |S_2| \times \cdots \times |S_n|)$

### 2. 下划线法 (Underline Method)

**可视化方法**（适用于二人博弈）：

1. 对于每列，标记玩家1的最大效用
2. 对于每行，标记玩家2的最大效用
3. 两个标记都有的格子就是纳什均衡

**例子**：

|       | L         | R         |
|-------|-----------|-----------|
| **T** | **3**,1   | 0,**0**   |
| **B** | 1,**3**   | **2**,2   |

下划线：玩家1在每列的最大值，玩家2在每行的最大值

纳什均衡：$(B, R)$ - 两个标记都有

### 3. 最佳响应对应 (Best Response Correspondence)

计算每个策略的最佳响应集合，找到不动点：

$$BR(s^*) = s^*$$

其中 $BR(s) = (BR_1(s_{-1}), \ldots, BR_n(s_{-n}))$

## 经典例子

### 1. 囚徒困境

|       | C     | D     |
|-------|-------|-------|
| **C** | -1,-1 | -3,0  |
| **D** | 0,-3  | **-2,-2** |

**纳什均衡**：$(D, D)$
- 这也是占优策略均衡
- 不是帕累托有效（$(C,C)$ 更好）

### 2. 协调博弈

|       | A     | B     |
|-------|-------|-------|
| **A** | **2,2**   | 0,0   |
| **B** | 0,0   | **1,1**   |

**纳什均衡**：$(A, A)$ 和 $(B, B)$
- 多重均衡问题
- 还有一个混合策略均衡

### 3. 性别战争 (Battle of Sexes)

|       | O     | F     |
|-------|-------|-------|
| **O** | **2,1**   | 0,0   |
| **F** | 0,0   | **1,2**   |

**纳什均衡**：
- 纯策略：$(O, O)$, $(F, F)$
- 混合策略：$(\frac{2}{3}O + \frac{1}{3}F, \frac{1}{3}O + \frac{2}{3}F)$

### 4. 匹配硬币

|       | H     | T     |
|-------|-------|-------|
| **H** | 1,-1  | -1,1  |
| **T** | -1,1  | 1,-1  |

**纳什均衡**：
- 纯策略：不存在
- 混合策略：$(\frac{1}{2}H + \frac{1}{2}T, \frac{1}{2}H + \frac{1}{2}T)$

## 纳什均衡的性质

### 1. 稳定性

纳什均衡是一种 **自我实施** (self-enforcing) 的预测：
- 如果每个人都相信其他人会遵守，没有人有动机偏离

### 2. 非唯一性

很多博弈有多个纳什均衡：
- 协调问题（选择哪个均衡？）
- 均衡选择理论 (equilibrium selection)

### 3. 与帕累托效率的关系

纳什均衡不一定是帕累托有效的：
- 囚徒困境：$(D, D)$ 是纳什均衡但不帕累托有效
- $(C, C)$ 帕累托占优 $(D, D)$，但不是纳什均衡

### 4. 与占优策略的关系

$$\text{占优策略均衡} \subset \text{纳什均衡} \subset \text{可理性化策略}$$

## 计算复杂性

### 纯策略纳什均衡

- **检验**：多项式时间 $O(n \cdot \max_i |S_i|)$
- **寻找**：多项式时间（枚举所有策略组合）
- **存在性判定**：多项式时间

### 混合策略纳什均衡

**重要结果**：

**定理（Daskalakis, Goldberg, Papadimitriou, 2006）**：
在二人博弈中寻找混合策略纳什均衡是 **PPAD-complete** 问题。

PPAD (Polynomial Parity Arguments on Directed graphs) 是一个复杂性类：
- 可能比 P 难
- 可能比 NP-complete 容易
- 总是存在解

## 纳什均衡的扩展

### 1. ε-纳什均衡

策略组合 $s$ 是 **ε-纳什均衡**，如果：

$$u_i(s_i, s_{-i}) \geq u_i(s_i', s_{-i}) - \varepsilon \quad \forall i, \forall s_i' \in S_i$$

即：没有玩家能通过偏离获得超过 $\varepsilon$ 的额外效用。

**近似算法**：在多项式时间内可以找到 $\varepsilon$-纳什均衡。

### 2. 相关均衡 (Correlated Equilibrium)

玩家可以观察公共随机信号并相应地选择策略。

**性质**：
- 总是存在
- 包含所有纳什均衡
- 可以在多项式时间内计算

### 3. 贝叶斯纳什均衡

不完全信息博弈中的均衡概念。

## 应用

### 1. 经济学

- 寡头竞争（古诺模型、伯川德模型）
- 拍卖设计
- 公共物品供给

### 2. 政治学

- 投票行为
- 选举竞争
- 国际关系

### 3. 计算机科学

- 网络路由
- 负载均衡
- 安全协议

### 4. 生物学

- 进化稳定策略 (ESS)
- 种群动态

## 批评与局限

1. **多重均衡**：如何选择？
2. **计算困难**：PPAD-complete
3. **认知要求高**：需要完美理性和共同知识
4. **实验违背**：人类行为常常偏离纳什均衡预测
