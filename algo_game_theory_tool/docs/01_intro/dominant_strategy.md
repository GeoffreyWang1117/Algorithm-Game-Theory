# 占优策略与严格劣策略

## 数学定义

### 占优策略 (Dominant Strategy)

策略 $s_i^* \in S_i$ 是玩家 $i$ 的 **严格占优策略**，如果：

$$u_i(s_i^*, s_{-i}) > u_i(s_i, s_{-i}) \quad \forall s_i \in S_i \setminus \{s_i^*\}, \, \forall s_{-i} \in S_{-i}$$

即无论其他玩家选择什么策略，$s_i^*$ 都严格优于任何其他策略。

### 弱占优策略 (Weakly Dominant Strategy)

策略 $s_i^*$ 是 **弱占优策略**，如果：

$$u_i(s_i^*, s_{-i}) \geq u_i(s_i, s_{-i}) \quad \forall s_i \in S_i, \, \forall s_{-i} \in S_{-i}$$

且至少存在一个 $s_{-i}$ 使得不等式严格成立。

### 严格劣策略 (Strictly Dominated Strategy)

策略 $s_i$ 被 $s_i'$ **严格占优**（即 $s_i$ 是严格劣策略），如果：

$$u_i(s_i', s_{-i}) > u_i(s_i, s_{-i}) \quad \forall s_{-i} \in S_{-i}$$

理性玩家永远不会选择严格劣策略。

### 弱劣策略 (Weakly Dominated Strategy)

策略 $s_i$ 被 $s_i'$ **弱占优**，如果：

$$u_i(s_i', s_{-i}) \geq u_i(s_i, s_{-i}) \quad \forall s_{-i} \in S_{-i}$$

且至少存在一个 $s_{-i}$ 使得不等式严格成立。

## 例子

### 囚徒困境

|       | C     | D     |
|-------|-------|-------|
| **C** | -1,-1 | -3,0  |
| **D** | 0,-3  | -2,-2 |

对于玩家1：
- 当玩家2选择C时：$u_1(D, C) = 0 > -1 = u_1(C, C)$
- 当玩家2选择D时：$u_1(D, D) = -2 > -3 = u_1(C, D)$

因此 **D（背叛）是严格占优策略**，C（合作）是严格劣策略。

### 第二价格拍卖

在维克里拍卖中，**真实报价是弱占优策略**（这是一个深刻的结果！）

## 占优策略均衡 (Dominant Strategy Equilibrium)

如果策略组合 $s^* = (s_1^*, \ldots, s_n^*)$ 中每个 $s_i^*$ 都是玩家 $i$ 的占优策略，则 $s^*$ 是 **占优策略均衡**。

### 性质

1. **唯一性**：如果存在占优策略均衡，则它是唯一的纳什均衡
2. **强稳定性**：即使其他玩家偏离均衡，玩家也没有动机改变策略
3. **实现简单**：不需要预测对手行为，只需选择占优策略

### 稀缺性

占优策略均衡很少存在：
- 囚徒困境：$(D, D)$ ✓
- 协调博弈：不存在 ✗
- 石头剪刀布：不存在 ✗

## 重复剔除严格劣策略 (IESDS)

**迭代剔除算法**：

```
重复执行直到无法继续：
    对每个玩家 i：
        找出所有被严格占优的策略
        从 S_i 中删除这些策略
```

### 数学形式化

定义序列 $S^0, S^1, S^2, \ldots$：
- $S^0 = S$（初始策略集）
- $S^{k+1} = \{s \in S^k : s_i \text{ 在 } S^k \text{ 中不被严格占优}\}$

**收敛**：存在 $K$ 使得 $S^K = S^{k}$ 对所有 $k \geq K$。

称 $S^{\infty} = S^K$ 为 **可理性化策略集** (rationalizable strategies)。

### 关键性质

**定理 1（顺序无关性）**：无论以什么顺序删除严格劣策略，最终结果 $S^{\infty}$ 相同。

**定理 2（纳什均衡存活）**：所有纳什均衡都在 $S^{\infty}$ 中存活。

$$s^* \text{ 是纳什均衡} \Rightarrow s^* \in S^{\infty}$$

**定理 3**：如果 $|S^{\infty}| = 1$，则唯一元素是唯一的纳什均衡。

## 例子：IESDS

考虑博弈：

|       | L     | C     | R     |
|-------|-------|-------|-------|
| **T** | 3,0   | 2,1   | 1,2   |
| **M** | 1,1   | 2,2   | 4,0   |
| **B** | 0,0   | 1,3   | 3,1   |

**第一轮**：
- 对玩家1，策略B被M严格占优（对所有列）
- 删除B

|       | L     | C     | R     |
|-------|-------|-------|-------|
| **T** | 3,0   | 2,1   | 1,2   |
| **M** | 1,1   | 2,2   | 4,0   |

**第二轮**：
- 对玩家2，在剩余博弈中，策略R被C严格占优
- 删除R

|       | L     | C     |
|-------|-------|-------|
| **T** | 3,0   | 2,1   |
| **M** | 1,1   | 2,2   |

**第三轮**：
- 对玩家1，策略M被T严格占优（在L和C下）
- 删除M

结果：$S^{\infty} = \{(T,C)\}$，这是唯一的纳什均衡。

## IESDS 的局限性

### 弱劣策略

IESDS 只删除严格劣策略，不删除弱劣策略。原因：
- 删除弱劣策略的顺序会影响结果
- 可能删除某些纳什均衡

### 无法总是求解均衡

很多博弈经过 IESDS 后仍有多个策略组合：
- 石头剪刀布：$S^{\infty} = S$（无法删除任何策略）
- 性别战争：$S^{\infty} = S$

## 计算复杂性

对于二人博弈：
- **单轮检测**：$O(|S_1| \cdot |S_2|)$ 时间
- **完整 IESDS**：$O(|S_1|^2 \cdot |S_2| + |S_1| \cdot |S_2|^2)$ 时间

## 在机制设计中的应用

占优策略概念在机制设计中至关重要：

**目标**：设计机制使真实报告是占优策略（激励相容）

**例子**：
- 维克里拍卖（第二价格）
- VCG 机制
- 格罗夫斯机制
